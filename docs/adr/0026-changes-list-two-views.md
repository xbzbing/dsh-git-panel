# ADR-0026：变更列表的平铺 / 树形两种视图

- 状态：Accepted（2026-11-03）
- 相关：issue #99、`src/client/changes-tree.ts`、`src/client/ChangesTab.tsx`、`src/client/changes-rows.tsx`、`src/client/ChangesToolbar.tsx`、`src/client/selection-keys.ts`、`src/host/parser.ts`（`parseStatus`）、ADR-0008 / 0012 / 0013 / 0016

## Context

变更页一直是平铺列表：一次改动跨多个目录（重构挪目录、批量生成页面）时，读者只能在一长串扁平路径里用眼睛找目标文件。issue #99 提出按目录层级折叠，并顺带提出几件事：目录节点汇总变更数、目录级暂存 / 放弃、按路径过滤、记住选择。

这条需求落进现有结构时有几个必须先回答的问题：

1. **树在哪里建？** 快照的 `changes` 是 `git status` 的平铺结果。让 host 分组会为同一个路径逻辑再写一份实现，还要改 wire 形状；而路径折树在 client 已有纯函数（`file-tree.ts`，提交详情的文件列表在用）。
2. **虚拟列表怎么办？** 变更列表按固定行高做窗口化（issue #16 的大仓库限流），行高是窗口数学的输入。多出一种行就得让高度表也认识它，且 CSS 必须钉同一个值。
3. **目录操作凭什么安全？** 「放弃」只删工作区文件（ADR-0008），未跟踪条目若本身是仓库要整批拒绝。目录级操作绝不能把「目录前缀」这种 host 没校验过的 argv 素材塞进请求。
4. **选择集怎么复用？** 选择键是 `path:s` / `path:w`（同一路径的两侧独立），组头已经有三态全选。
5. **视图选择存哪？** 首版存浏览器 `localStorage` 并带了路径过滤；面向小屏幕落地时改了主意：过滤框挤占本已紧张的一行，而「记住选择」天然是安装级偏好（换浏览器不该重选）。于是视图进插件配置、过滤整个砍掉——写配置要付一次快照飞行的代价，由「安装级一致」的收益换掉。

备选方案：

- **host 侧分组**：wire 多一份树结构，client 还要还原成行。不采用。
- **新开一个视图 / 页签**：行契约、工具栏、选择语义都要第二份。不采用。
- **视图模式进 host 配置**：曾以「写配置 = 一次快照飞行」为由不采用，后改为采用（见上）；浏览器 `localStorage` 方案随之废除——两处持久化只会互相打架。
- **目录放弃沿用行内的「再点一次」**：一个文件两击可接受，一棵子树两击太廉价。不采用。
- **路径过滤**：首版实现过（含过滤期间冻结折叠控件、命中临时展开祖先的一套状态），最终砍掉：小屏上它是挤占一行的奢侈品，超大变更集下 git 的正道是截断提示 + 「展开全部」，不是先过滤再操作；行内 `← 旧路径` 仍把重命名来源摆在眼前。

## Decision

- **一个纯函数出两种行**：`changes-tree.ts` 的 `buildChangeRows` 把「组 → 行」拍平成一份列表，平铺与树形只是同一份数据的两种走法。行的种类是 `head` / `dir` / `file`，行分发在 `changes-rows.tsx` 的 `renderChangeRow`（`ChangesTab` 只注入选择 / 对话框 / 查询的上下文）。目录树复用 `file-tree.ts`（同目录先于文件排序、单子目录链折成 `src/client` 一行）。
- **行高按种类钉死**：`ROW_H` 表（`changes-tree.ts`）`head` 26 / `dir` 26 / `file` 28，CSS 用 `.gp-changes__vrow>…{height:100%}` 跟随同一批行种。两侧契约都有锁：`test/unit/changes-row-heights.test.mjs` 锁文本（高度表 + 三个子选择器），`test/e2e/child-geometry` 之外的 `test/e2e/changes-tree.mjs` 锁渲染几何（子行填满盒子、top 链相加、spacer 对齐、内容不溢出）。
- **折叠状态按「组 + 目录路径」记**：`dirKey(group, path)`。同一目录在「已暂存」与「更改」各有一行，两处独立折叠；切换仓库（`snapshot.root` 变化）时清空，避免旧检出留下的路径把新树的一层藏起来。折叠状态不持久化——只有视图模式持久化（进配置）。
- **目录的挑选复用组头全选**：目录行带 `changes`（其后代变更条目），三态勾选与「选择本组全部文件」是同一段 `selection-keys` 逻辑，没有第二套选择语义。折叠起来的目录照样能勾选其后代。
- **目录级操作只报它自己那些行**：`dirStageAction` 取该组这一侧的路径（已暂存 → 取消暂存，工作区 → 暂存），`dirDiscardPaths` 只取工作区侧。传的始终是「已经是变更条目」的路径，绝不传目录前缀，所以嵌套仓库 / 折叠未跟踪目录的既有拒绝（`nested-repo`）原样生效。
- **目录放弃走二次确认框**：复用批量放弃的对话框（同一套计数与未跟踪警示），标题用目录的**全路径**点明作用域（`src/util` 与 `lib/util` 不会渲染成同一个标题）。对话框只存目录身份，路径集每次渲染从当前行重新推导——快照轮询拿走几行，计数就跟着缩，确认的集合永远与屏幕上的承诺一致。行内的「再点一次」手势只留给单个文件。
- **视图选择进插件配置**：`changesView`（volatile，默认平铺），详情页「界面显示」区一组平铺 / 树形可改；**操作栏尾部的一个切换图标**点一下换另一种并写同一字段（`writePanelConfigField` → settings 服务 → `resyncAfterWrite()`），本地状态只覆盖写入的往返，写失败退回快照值。浏览器内不再持久化。
- **一个图标，画当前视图**：图标画的是「现在是什么」（平铺 = 三条等长线，树形 = 缩进行），点一下换到另一种，不并排摆两个按钮——小屏上一行宽度是稀缺资源，第二个按钮只是把「另一种」摆出来。代价是光看图分不清它是状态还是动作，所以按钮的可访问名同时说两件事（「当前平铺，点击切换到树形」），灰底（`--dsw-alias-bg-module-platform`）把它与旁边透明的动作按钮分开。
- **空间压缩时切换图标让位**：操作栏（`.gp-changes__toolbar`）是 inline-size 容器，容器查询在窄于「8 个动作按钮 + 切换图标」所需内容盒宽度时隐藏它（实测：28px 按钮 283px，触摸把按钮养到 34px 则为 337px，各留 1px 容差）。这保证其余动作恒为一行——也是把切换按钮放进操作栏、整条删除原「视图条」的直接原因。
- **重命名带上源路径**：`GitChange.oldPath`（可选，旧 host 不提供即读不到）由 `parseStatus` 在 R/C 的那一侧填上；行内以 `← 旧路径` 展示，悬停标题写 `旧 → 新`。git 只在索引侧报告重命名，工作区的移动仍是「删除 + 未跟踪」两条。

## Consequences

- **列表被 host 截断时组头仍是统计里的诚实总数（ADR-0013），组头全选隐藏**（`truncated` 按「已加载 < 总数」判定，与视图状态解耦）；目录徽标只数已加载的行。两者口径不同是有意的：目录节点描述的是列表内容。
- **重命名展示依赖 host 支持**：旧 host 的快照没有 `oldPath`，客户端读不到就只显示新路径，不会崩。
- **行的缩进是内联 `padding-left`**（平铺 20px，树形每层 +14px）。这意味着后续任何按档位改行内边距的 CSS 都要考虑内联样式会赢；`.gp-dir-row` 的触屏「操作常显」规则必须和 `.gp-file-row__actions` 一起写进 `layout.ts` 的 `hover:none` 媒体查询，目录操作按钮钉 26px（= 行高），任何设备都不溢出邻行。
- **配置写入的代价**：切换图标每点一次触发一次 settings 写入 + 两次快照飞行（`resyncAfterWrite` 立即一次、1s 后一次）。换来详情页与工具栏同源、换浏览器不丢。
- **没有路径过滤**：按旧路径搜索重命名这类需求本期不做；超大变更集靠截断提示 + 「展开全部」。
- **测试**：`test/unit/changes-tree.test.mjs`（折叠 / 目录目标 / 行序 / 截断口径 / 视图归一）、`test/unit/changes-row-heights.test.mjs`（行高契约文本两侧）、`test/unit/parser.test.mjs` 的重命名用例、`test/e2e/changes-tree.mjs`（切换图标的状态 / 图标 / 灰底 / 可访问名与写配置断言、配置默认视图、缩进与行高几何、折叠、目录级暂存与放弃、compact 让位与单行、stacked 档）、`test/e2e/changes-toolbar.mjs`（图标排序与指针档恒在位的边界）。
- **本期不做**：目录级「批量取消跟踪」、树形下的拖拽、跨组共享折叠状态、路径过滤（含 glob / 模糊匹配）。目录前缀的重新分组也不做——它会让 host 的 `isSafePath` 之外多出一条路径解析权威。

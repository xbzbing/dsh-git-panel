# ADR-0043：词级强调采用保守的 60% 启发式

- 状态：Accepted（2026-11-26）
- 相关：issue #156、ADR-0042、`src/client/diff.ts`、`test/unit/diff.test.mjs`

## Context

已配对的 `mod` 行会做词级强调：取公共前缀和后缀，把中间一段标成变化。旧实现只去公共前缀 / 后缀，于是无关行也常被整段强调——同一段测试包装、相同的缩进、括号或 `const` 前缀把公共部分撑得很大，剩下的差异几乎覆盖整行，强调色与增删整行底色重复，读者反而看不出改了什么。

备选方案：只在两侧行数相等时强调（简单，但排除不了等长块里的无关行，也会漏掉不等长块里的小编辑）；按相似度配对或对块做字符级 LCS / Myers（对齐更好，但需要预算控制和新的范围模型）。当前只在已配对的一行内做线性扫描，不改 Git 的行级 diff。

## Decision

词级强调仍用公共前缀 / 后缀确定变化区间。两种低信号情况关闭强调：共享的部分只有空白（缩进不代表语义相关）；变化区间占两侧各自去首尾空白内容的比例都严格大于 60%。比例按 Unicode 码点计算，区间坐标仍为 UTF-16 且不能切开代理对。60% 是保守的显示启发式，不是语义相似度保证；一侧仍大部分不变的插入、删除或小修改继续强调。

## Consequences

- 减少低信息量的强调底色；增删整行底色和文本始终保留，不影响 patch 内容、评论引用或行号。
- 启发式可能隐藏某些真实的大修改，也不能保证每对被强调的行都有语义关联。
- 回归需覆盖阈值边界（含首尾空白）、共享部分只有空白、全空白行、空串与 emoji 代理对边界。
- 该启发式与 ADR-0042 的块顺序互不依赖：以后只调整比例或引入相似度配对，可以只因这一份 ADR 的推翻而改。

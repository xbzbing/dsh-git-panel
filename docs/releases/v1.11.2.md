## 主要变更

- **空白会话中的输入框 Git 标记恢复可用**：新对话还没渲染视图标签栏时，点击输入框左侧的 Git 标记会打开右侧边栏的 Git 页，不再毫无反应；右侧边栏入口也不可用时会提示先发送第一条消息，并避免误触相邻会话的 Git 页签（#113）
- **再次点击收起只有 Git 页的右侧边栏**：右侧边栏已展开且只有 Git 页时，第二次点击输入框标记会收起侧栏，悬停提示同步切换；侧栏还有其他页面时仍只聚焦 Git，不会把其他页面一起关掉（#114）
- **游离 HEAD 的括号与间距修正**：游离 HEAD 的标记现在显示为 `dsh-git-panel (游离 HEAD)`，不再出现双层括号；仓库名与分支之间的间距从 6px 收紧到 4px，读起来更像一个整体（#115）

## English

- **The input-bar Git marker works again in a blank conversation**: when a new conversation has not rendered its view-tab row yet, clicking the marker opens the Git page in the right sidebar instead of doing nothing; if the sidebar entry is unavailable too, it says to send the first message, and no longer reaches into another conversation pane's Git tab (#113)
- **A second click collapses a Git-only right sidebar**: when the right sidebar is expanded with only the Git page in it, the same click collapses it and the tooltip follows; with another page present the click still focuses Git and leaves the other page visible (#114)
- **Detached HEAD parentheses and spacing**: a detached HEAD now reads `dsh-git-panel (detached HEAD)` instead of showing a double pair; the gap between the repository name and the branch is tightened from 6px to 4px so the two labels read as one marker (#115)

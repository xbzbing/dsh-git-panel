## 主要变更

- **文件浏览按 Java/Kotlin 约定折叠包路径**：`src/main/java` 现在显示为一个源码根，源码根里连续的单子目录包合并成 `com.example…` 一行，`main` / `test` 直接展开；开关在详情页「视图」区的「折叠 Java 包路径」，默认开启，关掉即回到物理目录树。展开、右键与预览仍按真实路径工作，旧宿主会自然退回物理树。
- **提交历史的日期列按语言自适应**：相对时间列不再固定 96px——中文「刚刚 / 26 天前」实测只要 53px，固定宽度会在右侧留一条空带，俄文这类长文案又刚好贴边。现在按当前语言的文案实测宽度并夹在 56–96px 之间，切语言即时重算。面板变窄时历史行先收起作者、再收起哈希，标题与时间始终保留；顺带修掉窄列下日期探出行右缘、选中底色盖不住日期的问题。
- **适配 dsh 0.2.2-rc.2**：`dsh.client.inject` 去掉平台 seed 已提供的边，只声明客户端包边；`Menu` 声明去掉平台已移除的 `getAnchorRect`，只描述插件实际用到的成员；host 端点的参数名即 wire 键名，改由测试钉住（#124）。
- **文档**：插件详情页改成「简介 → 仓库 → 功能」并精简条目，中英文 README 的「功能」「权限与数据边界」同步收敛；新增 ADR-0033（列宽策略）与 ADR-0034（包路径折叠）。

## English

- **Package paths fold by Java/Kotlin convention in the file browser**: `src/main/java` now shows up as one source root, a run of single-child package directories inside it collapses into one `com.example…` row, and `main` / `test` expand directly. The switch is "Fold Java package paths" under View on the detail page — on by default, off returns the physical tree. Expanding, context menus and previews still use real paths, and an older host simply falls back to the physical tree.
- **The commit history date column follows the language**: the relative-time column is no longer a fixed 96px — Chinese labels such as `刚刚` / `26 天前` measure 53px and left a band of empty space on the right, while long ones like the Russian text barely fit. It is now measured from the active language's own labels, clamped to 56–96px and recomputed on a language switch. As the panel narrows, history rows drop the author and then the hash, keeping the subject and the time; the same change fixes the date hanging past the row's right edge (and the selection fill stopping short of it) in a narrow column.
- **dsh 0.2.2-rc.2 compatibility**: `dsh.client.inject` no longer lists the edges the platform seed provides and declares only the client packages, `Menu` no longer describes the removed `getAnchorRect` and only names the members the plugin uses, and the host endpoints' parameter names — the wire keys — are pinned by tests (#124).
- **Docs**: the plugin detail page now reads intro → repository → features with shorter entries, the Chinese and English READMEs had their feature and data-boundary sections tightened, and ADR-0033 (column-width policy) and ADR-0034 (package folding) were added.

## 主要变更

- **文件浏览可直接编辑保存**：配置与文档类文件（json / yaml / xml / properties / md / txt / toml / conf / ini / cfg、`.gitignore`、`.env.*` 变体）在文件浏览里点开就能编辑保存；编辑器（CodeMirror 6）按需加载，保存前比对磁盘内容，被外部改过时拒绝覆盖并带回当前指纹，未保存的改动在编辑框右上角悬浮提示（#97）
- **变更列表平铺 / 树形双视图**：操作栏尾部一个图标随时切换（图标即当前视图）；树形按目录折叠并汇总每个目录的变更数，可整目录暂存或放弃，重命名显示旧路径；默认平铺，可在插件配置中改（#99）
- **历史搜索增加「文件 / 路径」范围**：历史不再只有消息 / 哈希两种范围；文件 / 路径按历史路径做不区分英文大小写的字面子串匹配，文件名与目录片段都可搜，作者、日期、分支筛选继续叠加；只匹配路径、不搜代码内容，已删除路径仍可命中（#103）
- **差异视图改为工具栏图标**：统一 / 对照的切换收到工具栏一个图标上（对照位显示旋转的对比图标），再点一次回到统一，不再占一行分段按钮（#108）
- **发布入口收敛**：变更页删掉提交框上方重复的「发布分支」条，发布与推送统一从工具栏上传图标进入
- **修复**：会话进了 worktree 也能切回仓库根；收起态的仓库图标不再被长名字挤扁；脏编辑草稿遇到选择不匹配时回停 stash 而不是丢弃；写盘状态检查移入文件锁，失败的写入会清掉临时文件（#102 / #101 / #105）
- **回滚**：撤销「会话目录跟随 working_directory」，恢复以会话创建时的 cwd 为准（#100 / #106）
- **内部**：新增 ADR-0024（工作区文件编辑边界）、ADR-0025（编辑器懒加载 chunk）、ADR-0026（历史路径搜索契约）、ADR-0027（变更列表双视图）；AGENTS 补工具栏尾部控件整组换行等 UI 约定

## English

- **Edit and save from the file browser**: config and document files (json / yaml / xml / properties / md / txt / toml / conf / ini / cfg, `.gitignore`, `.env.*` variants) now open in an editor and save in place; the CodeMirror 6 editor is loaded on demand, a save compares the bytes on disk and refuses to overwrite a file changed elsewhere (handing back its current fingerprint), and unsaved work is flagged in the corner of the editor (#97)
- **Flat and tree views for the changes list**: one icon at the tail of the action bar flips the view (the icon shows the current one); the tree folds by directory, counts each directory's changes, stages or discards a whole directory, and shows the old path on renames; flat stays the default and the choice lives in the plugin config (#99)
- **A "file / path" scope for history search**: history now searches by message / hash or by file / path; the path scope matches historical paths as a case-insensitive literal substring, so file names and directory fragments both work with the author, date and branch filters stacked on top; it matches paths only, not file contents, and deleted paths still hit (#103)
- **The diff view switch moves to a toolbar icon**: unified / split now toggles from one toolbar icon (the split slot shows a rotating compare glyph) and a second click returns to unified, instead of a full segmented row (#108)
- **One publish entry**: the duplicate "Publish Branch" strip above the commit box is gone; publish and push both start from the toolbar upload icon
- **Fixes**: a session that entered a worktree can switch back to the repository root; a collapsed repository icon is no longer squashed by a long name; a dirty edit draft returns to the stash instead of being dropped when the selection no longer matches; the write-state check moved inside the file lock and a failed write cleans up its temporary file (#102 / #101 / #105)
- **Reverted**: "session directory follows `working_directory`" is rolled back; the cwd captured when the session was created applies again (#100 / #106)
- **Internal**: new ADRs — 0024 (workspace file-edit boundary), 0025 (editor as a lazy chunk), 0026 (history path-search contract), 0027 (the changes list's two views); AGENTS records the toolbar tail cluster wrapping and other UI conventions

## 主要变更

- **输入框胶囊会自动跟随会话的 worktree 切换**：会话进入或退出本仓库的 linked worktree（如 `.agents/worktrees/*`）时，输入框的 Git 胶囊与面板自动切到该检出——不用先打开 Git 面板，也不用去仓库列表点一次；胶囊单独挂载也会跟。只跟随会话自己仓库的检出：无关的嵌套仓库、`.code-workspace` 认证的外部根和任意的 `workingDirectory` 改动仍要手动选择。自动选择只改内存、不写标签页记录；手动选过的仓库保持优先，挂载、重取窗口和探测失败时都不会被抢走。（#158）
- **统一差异按变更块重排，增删底色覆盖行号**：一段连续变更现在先列全部删除、再列全部新增，多行重写不再逐行交错；增删底色延伸到两列行号（含空白格）与符号格，边缘色条只留在代码列，split 只着色对应侧、before / after 保持中性；行号悬停与评论选中叠在底色之上而不覆盖它，键盘焦点轮廓仍然可见；词级强调只在有意义的行上出现——两侧共享部分仅有空白、或变化区吃掉了首尾空白的大部分时关闭。（#156 #157）
- **内部**：新增 ADR-0041 / 0042 / 0043；仓库列表、跟随状态、选择修复与快照控制器对齐收进每会话一个共享检出生命周期，胶囊与多个面板共用一个列表、同一轮扫描单飞，迟到应答不修复也不跟随新状态；差异块顺序、行号与色条规则补进 AGENTS 与双语 README。（#157 #158）

## English

- **The composer pill now follows the session's worktree switches by itself**: when the session enters or leaves a linked worktree of its own repository (such as `.agents/worktrees/*`), the Git pill in the input bar and the panel move to that checkout — no need to open the Git panel first, and no manual pick in the repository list; the pill follows even when no panel is mounted. Only checkouts of the session's own repository are followed: unrelated nested repositories, roots certified by `.code-workspace`, and arbitrary `workingDirectory` changes still need a manual pick. The automatic choice lives in memory only and never writes a tab record; a repository the user picked stays in front and is not taken over on mount, during a refetch, or when the worktree probe fails (#158)
- **Unified diffs are grouped by change block, and the add/remove tint now covers the line numbers**: a contiguous change lists all deletions first and then all additions, so a multi-line rewrite no longer interleaves line by line; the tint extends to both line-number columns (including their blank cells) and the sign cell, while the edge color bar stays on the code column only, split tints only its own side, and before/after stays neutral; line-number hover and review selection layer on top of the tint instead of replacing it, and the keyboard focus ring stays visible; word-level emphasis appears only where it means something — it turns off when the shared part is whitespace only, or when the changed spans eat most of the first/last whitespace (#156 #157)
- **Internal**: new ADR-0041 / 0042 / 0043; the repository list, follow state, pick repair and controller alignment now live in one shared checkout lifecycle per session, so the pill and every panel share one list and one in-flight scan, and a late reply neither repairs nor follows a newer state; the block-order, line-number and color-bar rules are recorded in AGENTS and both READMEs (#157 #158)

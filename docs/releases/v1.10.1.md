## 主要变更

- **切换存储库更快**：点一行切换后列表保持展开，连续换仓库只需每次点一下；标题行整行都能点开或收起。切回一个轮询周期内读过的仓库会立刻显示它上一次的状态，不再压暗等待。新增配置「切换存储库后收起列表」，默认关闭（#95）
- **列表选中样式统一**：分支树、提交历史、提交详情的文件、变更列表、文件树、存储库列表的选中行都改为同一块滑动填充，左侧是垂直蓝条，换选中项时平移过去；三个字号档下都与选中行对齐。当前检出的分支用橙色标签图标和绿色 `HEAD` 胶囊标出（#95）
- **变更统计条改为胶囊**：文件数、增删行数、已暂存 / 已修改 / 未跟踪各占一枚；中文、日文以外的界面语言统一显示 `Files / Staged / Modified / Untracked`。存储库列表的展开收起带高度动画，标题行展开时也保留存储库图标；分栏分隔条双击恢复默认宽度或比例；回到面板时直接显示上次停留的子页签，不再先闪一下总览（#95）
- **内部**：CI 新增 Windows 单测任务（windows-2025，node 24.x）；单测在没有符号链接权限的 Windows、以及临时目录位于某个仓库内的环境下也能运行（#96）

## English

- **Faster repository switching**: picking a row keeps the list open, so switching repeatedly takes one click each; the whole head line now opens and closes the list. Returning to a repository read within one polling interval shows its last state immediately instead of dimming and waiting. A new setting, "Collapse the list after switching repositories", is off by default (#95)
- **One selection style for every list**: the branch tree, commit history, commit-detail files, the changes list, the file tree and the repository list now mark the selected row with the same sliding fill, a straight blue bar on the left, which glides to the new row; it lines up with the row at all three font sizes. The checked-out branch carries an orange tag icon and a green `HEAD` chip (#95)
- **Change statistics as chips**: file count, line changes, and staged / modified / untracked counts each get a chip; UI languages other than Chinese and Japanese show `Files / Staged / Modified / Untracked`. The repository list animates its height when it opens or closes, and its head keeps the repository icon while open; double-clicking a pane divider restores the default width or ratio; returning to the panel shows the last sub-tab directly instead of flashing the overview first (#95)
- **Internal**: CI adds a Windows unit-test job (windows-2025, node 24.x); unit tests also run on Windows without symlink permission and where the temp directory sits inside a repository (#96)

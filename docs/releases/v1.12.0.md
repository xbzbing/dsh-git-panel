## 主要变更

- **全站右键菜单**：文件、目录、预览图片、分支、提交、变更、贮藏、仓库行和输入框上的分支标记都能右键。文件与目录借用侧边栏的公开动作——浮窗打开、在 Finder 中显示、用默认应用打开（带应用图标）、复制路径、下载 / 另存为（不提供「在侧栏打开」）；分支行可切换、只看该分支历史、复制分支名；提交行可复制哈希与说明、建标签、还原 / 重置；变更行可打开差异、暂存 / 放弃；贮藏行可应用、弹出、复制说明、删除。破坏性项仍复用既有二次确认框，目标在手势时捕获并在解析前复核仓库归属。需要 dsh ≥ 0.2.2-alpha.3，旧版本右键保留浏览器原生菜单（#116、#107）
- **与修订版本 / 分支或标签比较，看文件的 Git 历史**：总览、变更与文件页右键即可拿任意提交、分支或标签做单文件对照，或打开该文件的提交历史。两个选择框按现行 UI 重做：分组标题带数量、搜索框带剩余计数与无匹配提示、提交行两行（说明 + 短哈希 / 作者 / 相对时间）、↑↓ 跳过分组标题并用 Enter 比较当前行、底部按键提示（#116）
- **提交可检出为游离 HEAD**：host 声明 `commitCheckout` 能力时提交行多出检出项，未声明的旧 host 不显示这一项（#116）
- **引用到输入框**：文件、目录和提交可以右键引用到会话输入框，输入框里的分支标记同样可右键跳页签、复制分支名、检查远端（#116）
- **修复**：比较一个不存在的修订版本（已删除的分支、拼错的 ref）不再显示成「两边一模一样」，改为报出 git 自己的错误；图片比较另外区分「修订版本里没有这张图」和「引用根本不存在」（#116）
- **修复**：比较与历史请求按会话仓库绑定并在解析前复核，菜单打开期间提交行的悬停卡片先收起，暂存 / 放弃以手势时捕获的路径为准（#116）
- **状态条忙碌态**：拉取、推送、切换分支时不再显示与右侧刷新按钮重复的加载圈，只保留说明文字与刷新按钮的动效
- **内部**：三轮独立评审的修复项落地——`.git` 路径在文本与图片比较中一律拒绝、分支列表用 `%(symref)` 过滤符号引用、菜单图标与分隔线按族注册；比较与历史测试钉住默认分支名，并改用 Windows 合法的文件名（#116）

## English

- **Context menus everywhere**: right-click files, directories, previewed images, branch and commit rows, changes, stashes, repository rows and the input-bar marker. Files and directories borrow the sidebar's public actions — open in a floating pane, reveal in Finder, open with the default application (with its icon), copy the path, download / save as (no "open in sidebar"); branch rows switch, filter the history to that branch and copy the name; commit rows copy the hash and the message, create tags, revert or reset; change rows open the diff, stage or discard; stash rows apply, pop, copy the message or drop. Destructive items reuse the existing confirm dialogs, and a target's repository identity is captured at gesture time and re-checked before it resolves. Requires dsh ≥ 0.2.2-alpha.3; older versions keep the browser's native menu (#116, #107)
- **Compare against a revision, a branch or a tag — and see a file's history**: from the overview, changes and files pages, put any commit, branch or tag side by side with a single file, or open that file's Git history. Both pickers follow the current UI: grouped headings with counts, a search box with a remaining-count and no-match hint, two-line commit rows (subject + short hash / author / relative time), ↑↓ that skip group headings and Enter to compare the row under the cursor, plus a key-hint footer (#116)
- **Check commits out as a detached HEAD**: the commit row gains the item when the host declares the `commitCheckout` capability; older hosts that do not declare it simply do not show it (#116)
- **Quote into the composer**: files, directories and commits can be quoted into the session composer, and the input-bar marker right-clicks into page jumps, branch-name copy and remote checks (#116)
- **Fix**: comparing against a revision that does not exist (a deleted branch, a mistyped ref) no longer reads as "no differences" — it reports git's own error; image comparison additionally tells "the revision predates this picture" from "this revision does not exist" (#116)
- **Fix**: compare and history requests are bound to their session's repository and re-checked before they resolve, the commit hover card closes while a menu is open, and stage / discard act on the paths captured at gesture time (#116)
- **Status bar while busy**: pulling, pushing and switching no longer show a loader next to the label that repeats the refresh button's spin — the label and the button's animation stay
- **Internal**: three rounds of independent review landed — `.git` paths rejected in text and image compares, the branch list filters symbolic refs via `%(symref)`, menu icons and separators are registered per family; compare and history tests pin the default branch name and use a Windows-legal filename (#116)

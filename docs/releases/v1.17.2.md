## 主要变更

- **可以自定义 AI 生成提交信息的规范**：插件详情页的「AI 生成提交信息」新增自定义提交规范，保存后作用于本插件的所有仓库；自定义规范优先于仓库历史风格，清空草稿并保存即恢复内置默认，生成语言仍由语言设置控制。规范最多 16 KiB（UTF-8），只约定格式与详略，不执行其中的命令。（#159 #160）
- **默认指令和保存后的最终提示词都能查看**：两个只读弹窗分别展示内置指令，以及已保存配置实际使用的 system 指令与 user 末尾提醒，中英两版逐字呈现。查看只读本插件自己的指令，不含真实 diff、会话上下文，也不调用模型。「保存规范」只报告已保存，最终预览按需打开；规范无效时给出明确终态说明，不再引导重复重试。（#160）
- **内部**：生成与预览共用宿主唯一的 `buildSuggestPrompt`，输入与预览预算仍单源在 `types.ts`；新增不依赖仓库、fs 与模型的 `suggest-prompt` 查询；ADR-0014 与八份详情页同步；工具条收成一行，字节数按归一化后的 UTF-8 显示 `{bytes} B / 16 KiB`。（#160）

## English

- **Custom rules for the AI-generated commit message**: the **AI commit message** section on the plugin detail page now accepts custom writing rules. Saving applies them to every repository in this plugin; custom rules take precedence over historical style, and clearing the draft and saving restores the built-in default. The generation language still follows the language setting. Rules are capped at 16 KiB of UTF-8 and describe format and detail only; commands inside them are not executed (#159 #160)
- **Both the default instructions and the saved final prompts are inspectable**: two read-only dialogs show the built-in instructions and the exact system instructions / trailing user reminder used by the saved settings, in both Chinese and English. Viewing only reads this plugin's own instructions — no real diff or session context, and no model call. **Save rules** now only reports that the rules were saved; the final preview opens on demand. Invalid saved rules get a terminal explanation instead of a retry that cannot succeed (#160)
- **Internal**: generation and previews share the host's single `buildSuggestPrompt`; input and preview budgets stay single-sourced in `types.ts`; a mock-free `suggest-prompt` query resolves before repository, fs and model access; ADR-0014 and all eight detail pages are updated; the action row is a single line and the counter shows normalized UTF-8 bytes as `{bytes} B / 16 KiB` (#160)

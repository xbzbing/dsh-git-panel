## 主要变更

- **修复**：提交与 AI 摘要更可靠——同时勾选暂存与工作区改动时，工作区侧的删除不再从提交里丢失；Git 状态输出被截断时不再把空摘要交给模型，改为明确报错；行读取超过上限会直接说明原因，而不是返回空的文件结尾
- **修复**：路径与凭据安全——含 glob 元字符（如 `app/[id].tsx`）的文件路径按字面处理，放弃 / 暂存不会误伤其它匹配同名模式的文件；远程地址里的凭据彻底剥离（含未编码 `@` 的密码）；字面路径限定只对真正接收路径列表的子命令生效
- **修复**：交互与数据状态——传输中断时面板显示「数据可能过期」并保留上一份快照，不再伪装新鲜、也不再降级成「没装 git」；提交详情的截断状态有横幅提示；diff「展开全部」分批走完全程，被拒时给出原因；分支行支持键盘操作（Tab 可达、Enter 应用筛选、聚焦即现「切换分支」按钮）；在途写操作锁住弹窗、放弃必须两次真实点击；静态预览 CSP 真正生效，mermaid 切换文档时输入框不再抖动
- **内部**：发布工作流拆成只读门禁与发布两个 job、第三方 action 全部 pin 到 commit SHA；总览行 / 分支 / diff、变更行与贮藏弹窗、版本条、op-runner 等同构模块拆分完成，本批全部修复带回归测试入库

## English

- **Reliable commits and AI summaries**: with staged and worktree changes selected together, worktree-side deletions no longer drop out of the commit; a truncated Git status now reports an error instead of handing an empty summary to the model; a line read over the limit states the reason instead of returning a false end of file
- **Path and credential safety**: paths containing glob metacharacters (such as `app/[id].tsx`) are handled literally, so discarding or staging never touches other files matched by the same pattern; credentials embedded in remote URLs are fully stripped (including an unencoded `@` in the password); literal pathspec mode applies only to the subcommands that actually receive a path list
- **Interaction and data state**: on a transport outage the panel shows "data may be stale" while keeping the last snapshot, instead of pretending to be fresh or degrading to "git not installed"; truncated commit details carry a notice; diff "expand all" walks every batch and reports the reason when a reveal is refused; branch rows are keyboard-operable (Tab-reachable, Enter applies the filter, focusing a row reveals its Switch button); in-flight write operations lock their modals and discarding requires two real clicks; the static-preview CSP now takes effect, and switching documents no longer jitters the input box under mermaid
- **Internal**: the release workflow splits into a read-only gate job and the publishing job, with every third-party action pinned to a commit SHA; the overview rows / branch / diff, changes rows and stash modal, version bar and op-runner modules are split out, and every fix in this batch ships with regression tests

## 主要变更

- **Git Flow 工作流**：分支列表新增 Git Flow 入口，可以直接开始 `feature/`、`release/`、`hotfix/` 分支，也可以在完成后把 release / hotfix 合入主线、打 annotated 标签并回并 `develop`；开始与完成前都先给出分支变更预览，确认后才执行（#133）
- **完成操作改为逐步确认，并要求工作区干净**：完成对话框列出这次会做的事——合并、打标签、推送长期分支、删除远端分支；要删远端必须在同一个确认里勾选，删除只认该分支解析出的上游并带 lease 与 expected OID 校验（#146）
- **start / finish 的预览与错误跟随真实 upstream**：预览按目标远端的真实上游显示将发生的分支移动、新标签与推送，不再是本地推测；远端已 ahead / diverged 时先做预检并说明原因（#146）
- **同一仓库同时只跑一个 Git Flow 操作**：按 common-dir 加锁，第二个操作直接回「进行中」而不是并发写；push 结果未知或中途失败时保留现场，支持安全续作与链式 release 的部分续作（#146）
- **可以关闭 Git Flow 入口**：不需要它的仓库可以在「什么是 Git Flow」底部关闭（带确认），关闭后总览与分支菜单不再出现入口；插件详情页新增开关，随时可以重新打开，旧 host 不下发该字段时按开启处理（#146）
- **Git Flow 使用文档**：新增中英文使用指南（基本概念、分支图、从 Feature 到 Release / Hotfix 的案例）与 8 张界面截图，README 的 Git Flow 段落改为链接公开文档与 ADR-0037（#146）
- **内部**：两支 e2e runner 在系统 Chrome 下的假红已修复（复制结果断言与 favicon 夹具），全套 38 支 runner 可在本机一次跑通（#147）

## English

- **Git Flow workflow**: the branch list now has a Git Flow entry for starting `feature/`, `release/` and `hotfix/` branches, and for finishing a release / hotfix by merging into the mainline, tagging it (annotated) and merging back into `develop`; each start and finish shows a preview of the branch changes before anything runs (#133)
- **Finishing is a step-by-step confirmation and requires a clean worktree**: the finish dialog lists what will happen — merges, tags, pushes to long-lived branches, deleting the remote branch; deleting the remote must be ticked in that same confirmation, and only the branch's resolved upstream is deleted, with a lease and an expected-OID check (#146)
- **Start / finish previews and errors follow the real upstream**: the preview reads the target remote's actual upstream instead of guessing locally, and an ahead / diverged remote is pre-checked and explained before anything runs (#146)
- **Only one Git Flow action runs per repository at a time**: a per-common-dir lock rejects a second action with "in progress" instead of writing concurrently; an unknown push result or a mid-sequence failure keeps the scene intact and can be resumed, including chained releases (#146)
- **The Git Flow entries can be turned off**: repositories that do not need them can switch them off from the bottom of "What is Git Flow" (with a confirmation), after which the overview and branch menus stop showing the entries; the plugin detail page gained a switch to turn them back on, and an older host that does not send the field is treated as on (#146)
- **Git Flow documentation**: a new Chinese/English guide (concepts, branch diagram, a Feature → Release / Hotfix walkthrough) plus eight UI screenshots; the README's Git Flow sections now link the public guide and ADR-0037 (#146)
- **Internal**: two e2e runners no longer fail falsely under system Chrome (the copy-result assertion and the `favicon.ico` fixture), and all 38 runners pass in one run locally (#147)

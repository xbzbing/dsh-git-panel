## 主要变更

- **文件树每行只剩一种字体**：折叠后的 `src/main/java` 这类包路径行不再单独换成等宽字体，整棵树的行保持一致。等宽字体的 x-height 更小、字面更宽，混在同一列里读起来像「这一行变小了」。
- **悬停提示不再压到隔壁面板**：气泡宽度按控件所在面板收窄（侧边栏通常比窗口窄），贴近右边缘时整体左移，不再盖到旁边一栏。
- **超长路径的文字留在气泡里**：`width:max-content` 配合 `max-width` 时浏览器按未夹取的宽度断行，行尾会被画到圆角外（盒子尺寸反而是对的）。现在允许在任意位置断行，路径再长也不越出气泡。

## English

- **One font for every file-tree row**: folded package paths (`src/main/java` and friends) no longer switch to a monospace face, so the tree keeps a single voice. Monospace has a smaller x-height and wider advance, which read as "this row shrank" inside the same column.
- **Hover tips stay inside their own panel**: the bubble narrows to the panel that owns the control (a sidebar is narrower than the window) and shifts left near the right edge instead of covering the pane beside it.
- **A long path no longer escapes its bubble**: with `width:max-content` plus `max-width`, the browser breaks lines at the unclamped width and paints the tail outside the rounded corner — while the box itself measures fine. Breaking anywhere keeps every character inside the bubble.

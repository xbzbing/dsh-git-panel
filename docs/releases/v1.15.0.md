## 主要变更

- **分叉状态有了「同步」入口**：本地领先且落后时，两个入口原本都不给任何动作，只能去终端；现在状态栏与变更页工具条都提供一次确认的「同步」——先合并上游，合并后仍严格领先才普通推送，全程不 force。确认框写明分支与领先/落后数量，切换分支或新提交到达时自动作废，不会对新目标动手（#141 / #143）
- **提交差异弹窗新增只读「文件」视图**：一个按钮切到带高亮与行号的整份文件，不必只看 diff 片段；「复制变更后的文件内容」按该版本全文读取，不再受 diff 上下文限制；源码预览支持 Ctrl/⌘+A 全选，超大的文件在虚拟窗口里只选已挂载行并给出常驻提示（#134 / #139）
- **状态栏状态改用符号，并按自身宽度降级**：窄栏里「已与远程同步」曾被截成「未跟…」；现在稳定状态显示 `✓` / `↑n` / `↓n` / `↓n ↑n` / `HEAD`，完整句子进无障碍名称与悬停提示，动作按钮在窄档只留图标（#131 / #132）
- **弹窗图标按钮改用平台 Tooltip 气泡**：悬停即时出现深色气泡，不再等原生 title 那半秒以上的延迟；平台未导出该原语时自动回退到 title，旧环境不会丢提示（#142）
- **修复**：变更记录的两行表头常驻（空分组显示 `(0)` 并保留折叠与全选控件），干净工作区的提示在表头下方居中，不再靠表头消失来暗示「没有该分组」（#135 / #138 / #140）
- **修复**：领头缝隙与「向上展开」点下去毫无反应——写回切片时按展开前的地址找不到缝隙；现在按 gap 自身地址定位，行数与缝隙都按预期变化（#136）
- **修复**：切到「文件」视图后工具栏从 6 个按钮塌成 3 个，看起来像坏了；现在 diff 控件保留且可用，点模式或展开会先执行动作再切回 diff
- **修复**：列表变短后首帧仍按旧滚动位置取窗口，偏移越过末行时会空一帧且表头也不见；取窗前先把偏移夹到新底部
- **内部**：新增 ADR-0036 记录分叉同步的取舍（拒绝 `--force-with-lease` 与默认 rebase，也不把计数做成按钮），ADR-0007 只追加指针、原文不重写

## English

- **Diverged branches now have a "Sync" entry**: when the branch is both ahead and behind, neither entry offered any action and the only way out was a terminal; the status bar and the changes toolbar now offer a single confirmed "Sync" — merge the upstream, then push normally only if still strictly ahead, never with force. The confirm dialog names the branch and both counts, and is discarded when the branch or HEAD moves, so it never acts on a different checkout (#141 / #143)
- **The commit diff dialog gained a read-only file view**: one button switches to the whole file with highlighting and line numbers instead of only the diff hunks; "copy the changed file's contents" reads that version's full text rather than the diff context; source preview supports Ctrl/⌘+A, and very large files in the virtual window select only mounted rows with a persistent notice (#134 / #139)
- **The status bar uses symbols and degrades by its own width**: in a narrow column "synced with remote" was truncated to "Not f…"; stable states now read `✓` / `↑n` / `↓n` / `↓n ↑n` / `HEAD`, the full sentence lives in the accessible name and tooltip, and action buttons keep icons only when dense (#131 / #132)
- **Dialog icon buttons use the platform Tooltip bubble**: the dark bubble appears immediately on hover instead of waiting out the native title delay; when the platform does not export that primitive it falls back to `title`, so no tooltip is lost (#142)
- **Fixes**: the changes list keeps both group headers (an empty group shows `(0)` and retains its fold and select-all controls), and the clean-worktree hint is centered beneath them instead of implying "no such group" by hiding a header (#135 / #138 / #140)
- **Fixes**: the leading gap and "expand upward" did nothing — the slice was written back through the pre-expansion address and could not find its gap; it is now located by the gap's own address (#136)
- **Fixes**: switching to the file view collapsed the toolbar from six buttons to three, which read as broken; the diff controls now stay visible and usable, running their action and returning to the diff
- **Fixes**: after the list shrank, the first frame still took its window from the old scroll offset, leaving a blank frame with no headers; the offset is now clamped to the new bottom first
- **Internal**: ADR-0036 records the diverged-sync trade-offs (no `--force-with-lease`, no default rebase, and the counts stay non-clickable), and ADR-0007 only gains pointers with its original wording untouched

## 主要变更

- **在差异里给选中的行写评论，一键引用进输入框**：变更页、提交详情与版本比较的任意文本差异里，鼠标停在行号旁出现「+」，点它或行号选中一行，Shift+点击在同一侧扩展；写下意见后点「添加到输入框」或 Ctrl/⌘+Enter，评论以 `## User Comment N` + 文件 / 侧 / 行号 / 来源 / Diff hunk 的引用写进当前会话草稿，不自动发送。编号与平台「本地变更」页签插进来的评论连续，hunk 只带选中行前后各 3 行而不是整段上下文（#123）
- **差异工具栏新增「在「本地变更」中审阅」**：在会话工作目录所在的检出上，一键打开平台的「本地变更」页签并定位到当前文件。平台的可选包缺席、或当前选中的是别的仓库时不显示该入口，也不影响本插件加载（#123）
- **文件右键菜单改用平台「添加到对话」**：dsh 0.2.3 起插入的是可解析的 `@文件` 引用而不是纯文本路径；旧宿主或平台不再提供该项时，同一位置仍给回「引用到输入框」（#123）
- **仓库与文件浏览根的选择在当前标签页内保持**：安装 / 卸载任意插件触发的热重载、以及刷新页面，不再把选择清回会话工作目录的仓库；新开标签页仍从默认仓库开始。修复路径也收紧了：只有检出确实失效（确定的否决）才删记录，一次超时或读不到的探测不再毁掉刚恢复的选择（#151）
- **提交按钮改为分体下拉，可选「提交并推送」**：主按钮右侧 24px 箭头在「提交 / 提交并推送」之间切换，主按钮文字跟着变；选择记在本标签页的会话存储里（按会话），刷新与热重载都保持，新标签页回默认；不写插件配置。Ctrl/⌘+Alt+K 恒等于提交并推送且不改选择，但在确认框 / 放大卡片打开、按住不放、AltGr 或行内评论这类文本输入里不触发。推送不能快进（落后、无上游、游离 HEAD、空仓库、amend 已推送）时只提交，并用中性通知说明原因；推送被拒不会撤销提交；任何情况下都不 force（#152）
- **内部**：新增 ADR-0038 / 0039 / 0040；推送前置条件收敛到 `push-policy.ts` 的单一来源；行内评论的引用格式与平台 `formatReviewComment` 逐项对齐；e2e 的菜单选中态改为断言平台真实契约（选中样式与 `aria-keyshortcuts`），不再把 harness stub 的属性当成平台保证（#152）

## English

- **Comment on selected diff lines and quote them into the composer**: in any text diff (changes tab, commit detail dialog, version comparison), hovering a line number reveals a "+"; click it or the line number to select one line, Shift+click to extend on the same side. Write the comment and press "Add to input" or Ctrl/⌘+Enter: it lands in the session draft as a `## User Comment N` quote with Repository / File / Side / Lines / Source / Diff hunk, without sending. Numbering continues from comments the platform's own "Local changes" tab inserted, and the quoted hunk carries 3 lines of context around the selection rather than the whole expanded hunk (#123)
- **New "Review in Local changes" entry in the diff toolbar**: on the checkout that is the session working directory, it opens the platform's tab at the current file. The entry is absent when that optional platform package is missing or another repository is selected, and it never blocks this plugin from loading (#123)
- **The file context menu now uses the platform's "Add to chat"**: on dsh 0.2.3 it inserts a resolvable `@file` reference instead of a plain path; an older shell that no longer offers it gets the plugin's plain-path "Quote to input" in the same place (#123)
- **Repository and file-root picks now survive within the current tab**: a hot reload caused by installing or uninstalling any plugin, and a page refresh, no longer reset the pick to the session working directory's repository; a new tab still starts on the default. Repairs are also narrower: a record is deleted only when the checkout is definitively gone, so one timed-out probe no longer discards a pick that was just restored (#151)
- **The commit button is now a split button with "Commit and Push"**: the 24px caret to its right switches between Commit and Commit and Push, and the primary label follows the choice; the choice is remembered for the session in this tab, survives a refresh and a hot reload, and a new tab starts over on plain commit; it is never written to plugin config. Ctrl/⌘+Alt+K always means commit and push without changing the choice, but it stays out of the way of open confirmations or the enlarged diff card, a held key, AltGr, and text fields such as the inline review box. When the branch cannot fast-forward (behind, no upstream, detached HEAD, unborn, or amending a published tip) only the commit lands, with a neutral notice saying why; a rejected push never undoes the commit, and nothing ever forces (#152)
- **Internal**: new ADR-0038 / 0039 / 0040; the push preconditions collapsed into the single `push-policy.ts` source; inline review quotes now match the platform's `formatReviewComment` field by field; the e2e menu-selection assertion pins the platform's real contract (selected style and `aria-keyshortcuts`) instead of treating a harness-stub attribute as a platform guarantee (#152)

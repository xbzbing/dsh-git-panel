## 主要变更

- **`.code-workspace` 里的仓库也能切换**：新增插件配置 `codeWorkspace`（默认 `off`，可选 `auto` 或工作区内的文件名）。开启后，会话目录里那个 `.code-workspace` 文件列出的目录会进入仓库切换器——会话开在「枢纽」目录、真正干活的仓库是它的兄弟目录时，不必再把会话开到共同父目录。每个根都要先通过 `git rev-parse --show-toplevel` 确认，条目里的 `name` 用作显示名；选中该行后，文件浏览与编辑一起跟随到那个根，规则不变（#121、#122）。
- **没有上游时可以直接设置上游**：本地分支没有上游、但远端已有同名分支且与 HEAD 同提交时，同步按钮从「发布」变成「设置上游」。点击后在弹框里选一个远端（默认 origin），只写 `branch.<name>.remote` / `merge`，不推送也不联网；有多个远端时全部列为候选。设置失败时对话框留在原地显示错误，不用重开（#120）。
- **修复交互式 HTML 预览的中文乱码**：以前用 `blob:` 打开预览时按平台默认编码解码，非 ASCII 页面会变成乱码；现在固定按 UTF-8 解码页面内容。
- **`.code-workspace` 文件可编辑**：文件浏览里的 `.code-workspace` 进入编辑白名单，按 JSON 高亮；保存前按严格 JSON 校验，语法错误会标出行列并阻止保存，不再把整份文件当纯文本写入。
- **内部**：`.code-workspace` 扫描结果按 `(cwd, 文件, mtime, size)` 缓存 60 秒，到期整次重扫——先写文件、后克隆仓库的条目必然出现，同长度同 mtime 改写的旧答案也最多存活 60 秒；单次扫描的尝试数封顶 200（产出仍封顶 20 个根），避免一个大文件拖住 `repo-list`。`repo-list` 增加 `codeWorkspace` 识别状态（`applied` / `missing` / `invalid` / `ambiguous`），浏览根菜单与切换器共用同一个 `label`。

## English

- **Repositories from a `.code-workspace` file are switchable**: the panel gained a `codeWorkspace` setting (default `off`, or `auto`, or the name of a file in the workspace). When it is on, the folders listed by that file join the repository switcher — a session can stay in its "hub" directory while the repositories it works in live beside it, instead of moving the session up to the common parent. Every root must first answer `git rev-parse --show-toplevel`, a folder's `name` is used as its display label, and selecting the row moves file browsing and editing to that root under the same rules (#121, #122).
- **Set an upstream when there is none**: when a local branch has no upstream but a remote already has a same-named branch at HEAD, the sync button reads "Set upstream" instead of "Publish". The dialog picks a remote (origin by default) and writes only `branch.<name>.remote` / `merge` — no push, no network; every remote is offered as a candidate. A failed attempt keeps the dialog open with the error instead of closing it (#120).
- **Fix mojibake in the interactive HTML preview**: the `blob:` preview used to decode the page with the platform default, turning non-ASCII pages into garbage; it now always decodes as UTF-8.
- **`.code-workspace` files are editable**: the extension joins the edit allow-list and highlights as JSON; saving validates strict JSON first and reports the offending line and column instead of writing the file through as plain text.
- **Internal**: the `.code-workspace` scan is cached per `(cwd, file, mtime, size)` for 60 seconds and rescanned whole on expiry — a folder whose repository is cloned after the file was written is bound to appear, and a same-length rewrite in the same mtime tick can go stale for at most a minute; one scan probes at most 200 folders (still producing at most 20 roots) so a large file cannot stall `repo-list`. `repo-list` gained the `codeWorkspace` recognition state (`applied` / `missing` / `invalid` / `ambiguous`), and the browse-root menu now shares the switcher's `label`.

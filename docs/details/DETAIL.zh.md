# dsh-git-panel

![dsh-git-panel](https://cdn.jsdelivr.net/gh/xbzbing/dsh-git-panel@main/docs/assets/banner-zh.png)

在对话工作区里提供 IDE 风格的 Git 面板：分支与提交历史、变更的暂存与提交、差异对照和文件浏览集中在一个常驻标签页，输入框左侧另有 zsh 风格的分支标记，对话过程中不必切到终端或 IDE。

## 功能

- **Git 总览**：分支 / 标签列表、可搜索的提交历史图、提交详情，点文件即看该提交里的差异。
- **变更记录**：逐文件或批量暂存、放弃，提交与 **Amend**，贮藏，增删行统计。
- **常用 Git 操作**：切换分支、增删标签、还原 / 重置提交；破坏性操作需二次确认，只改本地仓库、不自动推送。
- **AI 生成提交信息**：参照仓库既有提交风格生成，模型默认跟随当前会话，可在详情页固定。**生成会把 diff 内容发送给所选模型的供应商。**
- **输入框 Git 标记**：zsh 风格的 `<仓库名> (<分支>)`，绿色为已同步、橙色为有未提交变更，点击跳转面板。
- **多仓库切换**：自动识别 worktree 与子目录里的独立仓库，切换后总览、变更记录和输入框标记都作用于所选仓库。
- **文件浏览**：浏览工作区目录树，预览代码、Markdown（含 mermaid 图表）、HTML 与图片，非 Git 目录同样可用。
- **差异与源码查看**：统一 / 对照 / 变更前 / 变更后四种视图，语法高亮、词级强调、上下文按需展开、<kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>F</kbd> 就地查找。
- **窄面板 / 移动端**：按面板尺寸自动切换布局，侧栏和手机上都能用。
- **多语言**：界面跟随 DSH 系统语言，支持简体中文、English、日本語、Español、Français、Deutsch、Русский、Português。

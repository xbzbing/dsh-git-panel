# dsh-git-panel

在对话工作区里提供 IDE 风格的 Git 面板：分支与提交历史、变更的暂存与提交、差异对照和文件浏览集中在一个常驻标签页，输入框左侧另有 zsh 风格的分支标记，对话过程中不必切到终端或 IDE。

## 仓库

源码、权限与数据边界说明、问题反馈：<https://github.com/xbzbing/dsh-git-panel>

## 功能

- **Git 总览**：分支 / 标签列表、提交历史图与提交详情，点文件即看该提交的差异；历史可按“消息 / 哈希”或“文件 / 路径”搜索，并叠加作者、日期、分支筛选。相对时间列按界面语言自适应宽度，面板变窄时先收起作者、再收起哈希。
- **变更记录**：逐文件或批量暂存 / 放弃，提交与 **Amend**，贮藏，增删行统计；列表可切平铺 / 树形，支持目录级暂存与放弃。
- **常用 Git 操作**：切换分支、增删标签、还原 / 重置；破坏性操作二次确认，只改本地、不自动推送。
- **AI 生成提交信息**：参照仓库既有提交风格，模型默认跟随当前会话、可在详情页固定。**生成会把 diff 内容发送给所选模型的供应商。**
- **输入框 Git 标记**：zsh 风格的 `<仓库名> (<分支>)`，绿色已同步、橙色有未提交变更，点击跳转面板。
- **多仓库切换**：自动识别 worktree 与子目录里的独立仓库，切换后总览、变更记录和输入框标记一致生效。
- **文件浏览**：预览代码、Markdown（含 mermaid）、HTML 与图片，配置文件可直接编辑保存；Java/Kotlin 项目按路径约定折叠包，`src/main/java` 显示为一个源码根（可在配置里关闭）。
- **差异与源码查看**：统一 / 对照 / 变更前 / 变更后四种视图，语法高亮、词级强调、上下文按需展开、<kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>F</kbd> 就地查找。
- **窄面板 / 移动端**：按面板尺寸自动切换布局，侧栏和手机上都能用。
- **多语言**：跟随 DSH 系统语言，支持简体中文、English、日本語、Español、Français、Deutsch、Русский、Português。
- **右键菜单**：文件、目录、图片、分支、提交、变更与贮藏行均可右键操作，破坏性操作仍需二次确认。

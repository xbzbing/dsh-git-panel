# dsh-git-panel

Git-панель в стиле IDE в рабочей области беседы: ветки и история коммитов, индексирование и коммит изменений, сравнение и обзор файлов собраны в одной постоянной вкладке, а слева от поля ввода показан индикатор ветки в стиле zsh. Переключаться на терминал или IDE посреди беседы не нужно.

## Возможности

- **Обзор**: список веток и тегов, граф истории коммитов и сведения о коммите; щелчок по файлу показывает его изменения в этом коммите. Историю можно искать по «сообщению / хешу» или «файлу / пути». Поиск файла / пути находит буквальные подстроки в исторических путях без учёта регистра английских букв, включая имена файлов и фрагменты каталогов; фильтры автора, даты и ветви по-прежнему комбинируются. Содержимое кода не ищется; удалённые пути остаются доступными для поиска, переименование не отслеживает старое имя автоматически, Git может упростить часть истории слияний и боковых ветвей, а сведения о коммите по-прежнему показывают полный список файлов.
- **Изменения**: индексирование и отмена по одному файлу или пакетом, коммит и **Amend**, stash и статистика добавленных·удалённых строк; список переключается между плоским видом и деревом каталогов — со счётчиками по каталогам и индексированием / отменой для каталога; плоский вид по умолчанию, вид настраивается в настройках плагина.
- **Частые действия Git**: переключение веток, создание и удаление тегов, revert / reset коммитов; разрушительные действия требуют подтверждения, изменения остаются в локальном репозитории и не отправляются автоматически.
- **Сообщения коммитов от ИИ**: следуют стилю существующих коммитов репозитория; модель по умолчанию берётся из текущего сеанса и может быть закреплена на странице сведений. **При генерации содержимое diff отправляется поставщику выбранной модели.**
- **Индикатор Git в поле ввода**: `<репозиторий> (<ветка>)` в стиле zsh, зелёный при синхронизации и оранжевый при незакоммиченных изменениях; щелчок открывает панель.
- **Несколько репозиториев**: worktree и независимые репозитории в подкаталогах обнаруживаются автоматически; после переключения обзор, изменения и индикатор работают с выбранным репозиторием.
- **Файлы**: просмотр дерева каталогов рабочей области и предпросмотр кода, Markdown (включая диаграммы mermaid), HTML и изображений; работает и вне репозитория Git. Файлы конфигурации и документации (json / yaml / xml / properties / md / txt / toml / conf / ini / cfg, `.gitignore` и подобные) можно редактировать и сохранять прямо на месте. В проектах Java/Kotlin пути пакетов также сворачиваются по соглашению: `src/main/java` показывается как один корень исходников, а цепочка каталогов пакета с единственным подкаталогом объединяется в строку `com.example…` (включено по умолчанию; отключается в настройках плагина).
- **Сравнение и исходный код**: виды «объединённый / рядом / до / после» с подсветкой синтаксиса, выделением изменённых слов, раскрытием контекста по запросу и поиском на месте по <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>F</kbd>.
- **Узкая панель / мобильные устройства**: макет подстраивается под размер панели и работает и в боковой панели, и на телефоне.
- **Языки**: интерфейс следует системному языку DSH: Simplified Chinese, English, 日本語, Español, Français, Deutsch, Русский и Português.
- **Контекстные меню** — правый клик по файлам, каталогам, изображениям, веткам, коммитам, изменениям и stash: скопировать пути, показать в файловом менеджере, скачать / сохранить как, индексировать или отменить, переключить ветку, создать метку, revert или reset, цитировать в поле ввода, проверить внешний репозиторий; опасные действия требуют подтверждения.

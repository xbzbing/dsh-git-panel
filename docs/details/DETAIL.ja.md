# dsh-git-panel

会話ワークスペースに IDE スタイルの Git パネルを追加します。ブランチとコミット履歴、変更のステージとコミット、差分、ファイルブラウザーを常駐タブ 1 つにまとめ、入力欄の左には zsh 風のブランチ表示を置きます。会話の途中でターミナルや IDE に切り替える必要はありません。

## リポジトリ

ソースコード、権限とデータの扱い、不具合の報告：<https://github.com/xbzbing/dsh-git-panel>

## 機能

- **Git 概要**：ブランチ / タグ一覧、コミット履歴グラフ、コミットの詳細。ファイルをクリックするとそのコミットでの差分を表示します。履歴は「メッセージ / ハッシュ」と「ファイル / パス」で検索でき、作者・日付・ブランチの絞り込みも併用できます。相対時刻の列は UI の言語に合わせて幅を決め、パネルが狭いときは作者、次いでハッシュを畳みます。
- **変更**：ファイル単位または一括でのステージと破棄、コミットと **Amend**、スタッシュ、追加·削除行数の統計。一覧はリスト / ツリー表示を切り替えでき、ディレクトリ単位のステージと破棄に対応します。
- **よく使う Git 操作**：ブランチの切り替え、タグの作成と削除、revert / reset。破壊的な操作は確認を求め、変更はローカルにとどまり自動ではプッシュされません。
- **AI によるコミットメッセージ生成**：リポジトリの既存コミットのスタイルに合わせて生成します。モデルは既定で現在のセッションに従い、詳細ページで固定できます。**生成時には diff の内容が選択したモデルのプロバイダーに送信されます。**
- **入力欄の Git 表示**：zsh 風の `<リポジトリ名> (<ブランチ>)`。同期済みは緑、未コミットの変更があるとオレンジで、クリックするとパネルに移動します。
- **複数リポジトリの切り替え**：worktree とサブディレクトリ内の独立したリポジトリを自動で検出します。切り替えると、概要・変更・入力欄の表示がすべて選択したリポジトリを対象にします。
- **ファイル**：ワークスペースのディレクトリツリーを閲覧し、コード、Markdown（mermaid 図を含む）、HTML、画像をプレビューします。設定ファイルはその場で編集して保存できます。Java/Kotlin プロジェクトはパスの規約に従ってパッケージを折りたたみ、`src/main/java` を 1 つのソースルートとして表示します（設定でオフにできます）。
- **差分とソースの表示**：統合 / 左右比較 / 変更前 / 変更後の 4 つのビュー。シンタックスハイライト、単語単位の強調、コンテキストの随時展開、<kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>F</kbd> によるその場検索に対応します。
- **狭いパネル / モバイル**：パネルのサイズに合わせてレイアウトが切り替わり、サイドバーでもスマートフォンでも使えます。
- **多言語**：UI は DSH のシステム言語に従います。簡体字中国語、English、日本語、Español、Français、Deutsch、Русский、Português に対応しています。
- **右クリックメニュー**：ファイル・ディレクトリ・画像・ブランチ・コミット・変更・スタッシュの行を右クリックして操作できます。破壊的な操作は確認を挟みます。
